# Учебный набор и эталон

Основной набор содержит 200 полностью синтетических карточек, по 10 на каждый из 20 сценариев. Seed `20261120`, дата среза `2026-11-20`. У карточек технические номера вида `SYN-20261120-0001`. Случайными являются даты заявления и типовые суммы. Конкретное условие сценария задаёт отклонение или основание исключения. Ни одной записи из ведомственной ИС в наборе нет.

Готовый набор, словарь полей и материалы испытаний находятся в [data/synthetic](../data/synthetic/README_DATA.md). Эталон каждой карточки формируется из статусов, заранее заданных в сценарии генератора. Модельный анализатор запускается отдельно.

Проверяемые случаи включают полную и неполную оплату, переплату, пограничный ноль, подтверждённые и неподтверждённые освобождения, установленные и неизвестные пропуски документов, расхождения и пропуски дат, одинаковые даты, смешанные отклонения и аварийные работы с неприменимым R3. Тестовый файл с повторным номером предназначен для проверки отклонения выгрузки.

`NEED_DATA` учитывается как применимая проверка без результата FLAG/PASS. `NOT_APPLICABLE` в эталоне исключается из знаменателя покрытия. TP/FP/FN/TN рассчитываются на парах с бинарным результатом по обеим сторонам. Таблица четырёх статусов и список несовпадений позволяют увидеть и другие ошибки классификации. Измеренные результаты относятся только к заданным модельным сценариям.
